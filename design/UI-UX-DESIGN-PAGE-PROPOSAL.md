# UI/UX Design service page proposal

The UI/UX Design page uses the shared ITGS service-page layout with a distinct design-workspace visual. The hero connects a three-step user flow to a wireframe and a finished interface. The larger demonstration shows three connected onboarding screens and explains their information hierarchy, interaction states, and reusable patterns.

The example is marked **ITGS internal concept**, **Self-initiated concept · Not client work**, and **Illustrative data**. It has not been validated with real users. The page includes three use cases, four deliverables, four process stages with named outputs, four FAQs, a navy closing CTA, and the shared compact footer. Desktop and mobile layouts keep the same reading order.
