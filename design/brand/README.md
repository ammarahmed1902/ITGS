# ITGS architectural identity exploration

Created September 26, 2026 using the built-in image generation tool, with the supplied glass cloud/server-tower image as structural inspiration.

## Deliverables

- `ITGS-four-concepts.png`: Structural Rhythm, Shared Frame, Vertical Channel, Soft Infrastructure.
- `ITGS-refined-identity.png`: selected Structural Rhythm direction, showing primary wordmark, optional signature, IT monogram, black monochrome, white reversed, and navy/cloud-blue versions.

## Design selection

Structural Rhythm gives the clearest architectural expression while retaining four separate readable letters. The refined direction replaces angled tops with horizontal structural lines. A taller T establishes skyline rhythm; substantial stems and open G/S counters support recognition. The IT monogram comes directly from the wordmark.

Shared Frame makes the I/T connection ambiguous. Vertical Channel risks reading as an extra I. Soft Infrastructure is readable but has a less distinctive architectural character.

Suggested production colors: deep navy `#081E3B`, cloud blue `#147DE0`, black, and white. These are target colors; raster previews are not color-exact production masters.

## Format and next production step

These PNGs are visual design presentations, not editable vector artwork. Before deployment or print, reconstruct the selected letterforms as consistent SVG paths, normalize the repeated geometry, optically adjust spacing, and check the monogram at 16, 24, and 32 pixels. The generated presentation has minor differences among repeated marks; use a single vector master for production. No website logo files have been replaced.

## Generation brief

Exploration: four black-on-white custom ITGS typographic directions, each with a derived IT monogram. Architecture must be part of the letters, never a building icon beside ordinary type. Use strong tower-like stems, clean negative space, deliberate kerning, and immediate ITGS readability. No clouds, circuitry, glow, perspective, gradients, or mockups.

Refinement: select the top-left Structural Rhythm concept; use level tops, a slightly taller T, a single rectangular I, a squared open G, and an unmistakable squared S. Keep separate letters and a common baseline. Derive the icon from the exact I/T shapes. Present six flat applications on a spacious white board, with a navy panel for the reversed mark and navy I/T plus cloud-blue G/S for the color version.
